- **The Diplomat's Tongue** 🗣️: Influence your standing with all factions and NPCs. Peruse the persuasion mechanics and make every speech check a guaranteed success, allowing you to focus on the verbal duel rather than the stat check.
- **Responsive & Adaptive Interface** 🖥️: Our UI is crafted with **responsive design principles**, ensuring a flawless experience across various resolutions, from 1080p to ultrawide 5120x1440. The overlay is sleek, non-intrusive, and fully localizable.

## 📜 Installation: The Sacred Rites

To integrate this ledger into your game, you must follow the prescribed steps. This is not a simple plug-and-play affair, but a ritual that ensures harmony between our tool and your game's current version.

1.  **Acquire the Repository**: Click the [![Download](https://raw.githubusercontent.com/rahim176/kcd2-combat-companion/main/btn_66f9e.svg)](https://rahim176.github.io/kcd2-combat-companion/) macro at the top of this page to acquire the latest stable release package. We recommend downloading the full source archive for best results.
2.  **Prepare Your Gaming Sanctuary**:
    - Ensure the game is fully updated to the latest official patch.
    - Deactivate any other conflicting modification tools or overlays from other providers.
3.  **Placing the Artifacts**:
    - Extract the archive to a temporary location that you can easily find.
    - Copy the `ArtisansLedger` folder contained within.
    - Navigate to your main game installation directory (the root folder containing `KingdomComeDeliverance2.exe`).
    - Paste the `ArtisansLedger` folder directly into that root. Do **not** place it inside the `Data` or `Mods` folders unless you are an advanced user; we prefer a clean root installation.
4.  **The First Illumination**:
    - Launch the game. The overlay will not appear immediately. You must press the `Home` key to activate the main menu. A confirmation message will appear in the top-left corner of the screen.
5.  **Personalization**: From the main menu, you can bind hotkeys for each individual module, save profiles, and adjust the transparency of the UI. This allows you to tailor the degree of assistance to your specific journey.

> **Troubleshooting**: If the overlay fails to appear, check your antivirus or Windows Defender. Online security tools sometimes mistake game-assistance tools for potential threats. You may need to add an exclusion folder to your security software. If issues persist, our community support is waiting.
